## Research result (subagent, checked 2026-11-02; verify before relying on it)

- **Executor** (executor.sh, github.com/UsefulSoftwareCo/executor, formerly
  RhysSullivan/executor): **MIT**. Only the hosted Cloud is paid; the local CLI, desktop app and
  self-host build are free with no billing code. v1.6.11 (2026-10-22). Documents "the same API
  authenticated for two different accounts". Toolkits give one endpoint per set
  (`/mcp/toolkits/<slug>`, found in source, not docs). Per-tool policies (allow, require
  approval, block). Secrets in macOS Keychain, 1Password or file; self-host encrypts in SQLite
  with `EXECUTOR_SECRET_KEY`. Local HTTP at `127.0.0.1:4788/mcp` with a bearer token, or stdio
  `executor mcp`. Default surface is meta-tools (search, then invoke), not direct tools. Risks:
  young and fast-moving, toolkits documented only in source.
- **ToolHive** (stacklok/toolhive, Apache-2.0, v0.59.0): conservative alternative. Go binary,
  groups, `thv client register claude-code|codex --group`, OAuth refresh token per workload
  name (multi-account inferred from code, not documented).
- Rejected: MetaMCP (stale), IBM ContextForge (heavy; rejects two entries with the same URL and
  OAuth config), Docker MCP Gateway (needs Docker Desktop), mcp-proxy, supergateway, Microsoft
  MCP Gateway (not managers).
- Native fallback: Codex keys OAuth tokens by `{server_name}|sha256(type,url,headers)`
  (codex-rs/rmcp-client/src/oauth.rs), so two names on one URL do not collide. Claude Code's
  token keying is undocumented: two names on the same Cloudflare URL might share a login.
- Not verified: Executor's OAuth against Cloudflare, Supabase, Vercel and PostHog; whether
  Executor's stdio mode exposes toolkits; whether Executor can export and import connections
  and toolkits as a file.

  PATH). Not the Raspberry Pi. Not a public Cloudflare Tunnel (the box will hold production
